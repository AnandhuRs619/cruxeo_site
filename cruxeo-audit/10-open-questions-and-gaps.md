- Scope was discovered public routes on the supplied hostname, with sitemap pathname comparison. No authenticated, hidden, unlinked admin or private pages were accessed.
- Five sitemap URLs and one social image reference on cruxeo.com were recorded without requests to that separate host. Social accounts were not inspected and link availability was not verified.

- Mobile/tablet resizing and touch testing were not available in the exposed browser API. Responsive CSS was inspected; device responsiveness remains unverified.
- Full keyboard traversal, screen readers, contrast, reduced-motion runtime, modal focus trapping and multilingual behavior remain untested.
- Assistant panel was opened but no message was sent. No outbound contact or form submission was performed, so delivery and backend validation remain unverified.
- No Lighthouse or field Core Web Vitals, backend code, credentials, CMS account, dependency lockfile, analytics data or deployment configuration was available.

- Inline SVG icons remain in saved source HTML rather than being exported as standalone assets. No linked downloadable PDF/company profile was found; no fabricated documents directory/files were added.
- Original and rendered extraction can include hidden responsive/accordion copies. Page content is preserved as evidence; it is not final editorial approval.
