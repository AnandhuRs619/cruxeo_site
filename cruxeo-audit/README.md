## Supporting material

- `pages/`: individual page content and metadata.
- `public/assets/`: unchanged downloaded logos, icons, images, fonts and videos.
- `evidence/`: original HTML/CSS, HTTP headers, structured extraction, font mappings, anchor checks, rendered homepage evidence and five desktop screenshots.

The ZIP is a documentation/asset archive, not a runnable Next.js project. Original source evidence should be opened as text or in a controlled review environment; it can contain the website’s original script and external resource references. No server source, private credentials or unpublished assets are included.

Rights/provenance and unverified claims are identified in the asset inventory and gaps document. Do not treat copied marketing or legal claims as independent verification.
