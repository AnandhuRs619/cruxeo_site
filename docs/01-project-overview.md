# 01 - Project Overview

## 1. Executive Summary

This project involves the complete analysis, architectural design, and frontend development of a modern, high-performance website rebuilt with the **Next.js App Router**, **TypeScript**, and **Tailwind CSS**. 

The design language is directly modeled after the premium, dark-mode cosmic tech aesthetic of **Fyntic** (`https://fyntic.webflow.io/`), customized to represent the verified identity, services, and assets of the target company.

---

## 2. Project Objectives

1. **Design Reference Fidelity**: Replicate the sophisticated dark aesthetic, visual hierarchy, cosmic ambient glow, micro-interactions, floating pill navbars, and futuristic component styling observed in Fyntic.
2. **Company Identity Separation & Verification**: Ensure no proprietary branding, mock slogans, or placeholder template assets from Fyntic are mistakenly attributed to the target company. Request and audit the original company website (`cruxeo.com` inferred from workspace context `cruxeo_site`).
3. **Engineering Excellence**:
   - Modern Next.js App Router architecture (`src/app`).
   - Clean, modular TypeScript code with strict type definitions.
   - Utility-first responsive styling via Tailwind CSS.
   - Fluid micro-animations and entrance transitions via Motion (Framer Motion).
   - Accessible and validated contact forms using React Hook Form and Zod.
   - Production-ready asset optimization with Next.js Image and local video streaming.
4. **Complete Documentation Suite**: 11 structured specification documents in `docs/` detailing audits, design tokens, component architecture, SEO, and deployment.
5. **Turnkey Deliverable**: A fully functioning project, free of build or linting errors, packaged as a downloadable ZIP archive (`company-website-nextjs.zip`).

---

## 3. Scope of Work

### Core Pages
- **Home (`/`)**: High-impact hero section with particle overlay video, badge announcements, dual CTAs, social proof counters, feature pills ticker, human-robot connection showcase, interactive capability grids, tiered pricing/solutions overview, client testimonials, and newsletter CTA.
- **About (`/about`)**: Vision, mission, milestone timeline, core values, leadership team, and corporate culture.
- **Services (`/services`)**: Comprehensive overview of experiential tech, AI activations, robotics, drone light shows, and interactive installations.
- **Projects / Portfolio (`/projects`)**: Filterable project gallery with case study modal / deep-dive previews (e.g. Ignispectra, Nexplay, Synapse, Lumen Lab).
- **Blog / Insights (`/blog` and `/blog/[slug]`)**: Tech innovation thought leadership, event industry trends, and case previews with markdown/CMS rendering.
- **Contact (`/contact`)**: Interactive inquiry form with category selector, validation, office location in Dubai, UAE, direct WhatsApp CTA, and interactive FAQ accordion.
- **Custom 404 (`/not-found`)**: Cosmic-themed 404 error page maintaining site navigation and brand voice.
